# H8 實作紀錄：模型切換實驗

> 完成日期：2026-09-14

## 實驗設計：同一問題 × 三個免費模型
> 問題：「用 10 個字以內回答：台灣的正式國定假日制度幾月改制？」

| 模型 | 答案 | 差異 |
|---|---|---|
| upstage/solar-pro4:free（預設） | 「2026年1月（勞動節调休試行）」 | 詳細 |
| inclusionai/ling-3.0-flash-sante:free | 「2025年5月」 | 簡短 |
| meituan/longcat-2.0:free | 「5月」 | 極簡 |

→ **不同模型風格/知識差異明顯**，這正是切換模型的用處

## 切換方式（兩種，都實測）
### 臨時（單次）— 全域旗標，不需改設定檔
```bash
hermes -m inclusionai/ling-3.0-flash-sante:free -z "問題"
hermes --provider nous -m meituan/longcat-2.0:free -z "問題"
```

### 持久（改預設）— 寫入 config.yaml
```bash
hermes config set model.default meituan/longcat-2.0:free   # ✓ 寫入成功
hermes config set model.default upstage/solar-pro4:free    # ✓ 切回
```
實測輸出：`✓ Set model.default = ... in /home/t945935/.hermes/config.yaml`
驗證：`hermes config get model` 顯示即時生效
