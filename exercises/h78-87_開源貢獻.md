1. **Bug 修復**（崩潰、錯誤行為、資料遺失）

## 開發流程（從已安裝的 repo 出發）
```bash
cd ~/.hermes/hermes-agent
uv pip install -e ".[all,dev]"          # 加開發測試依賴
git checkout -b fix/description         # 功能分支
scripts/run_tests.sh                    # 跑測試
# 送 PR（按 CONTRIBUTING.md 規範）
```
- `scripts/dev-sandbox.sh`：獨立 HERMES_HOME 沙箱測試，不碰正式環境
- 各類開發文件：adding-tools / adding-providers / agent-loop / tools-runtime / session-storage…

## 更新機制（hermes update，實測）
```
hermes update --check → ☤ Update available: 101 commits behind origin/main
hermes update --plan → Install: git (v0.21.2 @ ee445299)；無運行服務，純 code swap
```
- `--check` / `--plan` 設計貼心：先看再動
- `--no-backup` / `--backup`：更新前備份控制
- 已安裝方式：git（clone 到 ~/.hermes/hermes-agent）；也支援 docker/nix
