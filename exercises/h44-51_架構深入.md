## H46 備份與回滾
### hermes backup（整包 zip）
```bash
hermes backup                 # 全量 zip：設定+技能+sessions+資料
hermes backup -q              # 快速：只抓 critical（config/state.db/.env/auth/cron）
hermes backup -o /tmp/x.zip   # 指定輸出
```
- `hermes update` 前建議先 backup（config 預設 pre_update_backup: false、backup_keep: 5）

### hermes checkpoints（檔案快照）
```
Checkpoint base: ~/.hermes/checkpoints  Total: 0 B（目前無快照）
```
- shadow git repo：每次 write_file/patch/terminal 前快照工作目錄 → 可 rollback
- 子指令：status/list/prune（GC）/clear（清光！）
