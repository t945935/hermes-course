## H32 Gateway：一切的訊息中樞（關鍵概念）
```
Gateway（常駐服務）= 各平台的橋樑
  ├─ Telegram/Discord/Slack… bot 連線
  ├─ cron 自動觸發（第 8 章！）
  └─ hermes send 的發送通道
```
- 子指令：`run`（前景）/ `start` / `stop` / `restart` / `status` / `install`（systemd 服務）/ `list` / `setup`（設定平台）/ `enroll`（relay 註冊）
- 實測：`hermes gateway status` → ✗ not running；`hermes gateway list` → 只有 default profile
- WSL 建議：`hermes gateway run`（前景，WSL 不建議 systemd）；可放 tmux/nohup

## H34 傳訊息：hermes send（無需 agent）
```bash
hermes send "訊息文字"                      # 送到平台的 home channel
hermes send -t telegram:chat_id "內容"      # 指定 chat
hermes send -t discord:#ops "內容"          # 指定頻道
hermes send -f report.txt "標題"            # 從檔案讀內容
hermes send "MEDIA:/path/img.png"           # 附檔傳送
```
- 特色：**不跑 LLM、不進 agent 迴圈**，純通道（可從任何 shell script 呼叫）
- 憑證復用 gateway 的 ~/.hermes/.env
