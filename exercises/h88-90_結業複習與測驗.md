## 解答（對完再往後看）

1. B（-z 單行模式）
2. A（~/.hermes/config.yaml）
3. C（-m 與 --model 同義；--provider 另指定 provider）
4. C（upstage/solar-pro4:free；另有 ling/longcat/laguna 免費）
5. A（MEMORY.md / USER.md，§ 分隔條目）
6. B（SKILL.md：frontmatter + 指引正文）
7. B（gateway 常駐才會 fire）
8. C（hardline blocklist，--yolo 也擋不住）
9. A（hermes mcp add）
10. A（兩個 -z 背景 + wait，實測 23 秒跑完兩任務）
11. D（jsonl/md/qmd/html/trace）
12. A（reference models 各答 + aggregator 彙整）

13. `hermes`（互動）/ `hermes -z "題"`（單行）/ `hermes -r <id>`、`--continue`（續接）
14. § 分隔；開新 session 只問「你知道我什麼？」若背得出來＝已注入生效
15. 技能＝知識包（SKILL.md 指引，index 5.2KB 省成本）；工具＝可呼叫函式（schema 全注入 39KB）
16. 它需要互動終端（rich prompt），pipe 會被擋；改用 pty（script）或真實終端
17. When to Use / Quick Reference / Procedure / Pitfalls / Verification
18. 同名 job（resume/remove 都會要求 ID）；或想要精確指定目標時
19. hermes mcp serve
20. 要求寫檔/改檔再讀回（我們做過 /tmp/hermes_code_test.txt 19 bytes 實證）
