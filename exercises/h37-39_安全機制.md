# H37-H39 實作紀錄：安全機制

> 完成日期：2026-09-14

## H37 指令批准系統（hermes approvals，dry-run 實測）
三級裁決，實測輸出：

### ① allow（放行）
```
command : ls ~          env-type: local
verdict : allow (exit 0)
detail  : no guard matched; would run without a prompt
```
→ 無害指令：直接跑，不詢問

### ② hardline-deny（硬性拒絕）⭐本課重點
```
command : rm -rf /      env-type: local
verdict : hardline-deny (exit 3)
rule    : recursive delete of root filesystem
detail  : matches the hardline blocklist (never bypassable,
          blocked even under --yolo / approvals.mode=off)
```
→ **最危險的指令有「不可繞過」黑名單**：連 --yolo 都擋得住！

### 相關指令/功能
- `hermes approvals suggest`：從歷史批准紀錄挖出常批准指令，建議加入 allowlist（減少打擾）
- `hermes approvals test "<cmd>"`：dry-run 只看裁決**不執行**
- `--yolo`：跳過危險確認（但 hardline blocklist 依然有效）
- `--accept-hooks`：自動接受 shell hooks（慎用）
