# H40-H43 實作紀錄：MCP 整合（Model Context Protocol）

> 完成日期：2026-09-14 ｜ 實測：context7 官方遠端 MCP

## H40 MCP 是什麼
MCP = 讓 agent 接上「外部工具伺服器」的開放協定。Hermes 是 MCP **client**（用外部工具），也能當 MCP **server**（`hermes mcp serve` 把對話暴露給其他 agent 用）。

## H41 增加伺服器（hermes mcp add，實測）
```bash
hermes mcp add context7 --url https://mcp.context7.com/mcp
```
連線結果：
```
✓ Connected! Found 2 tool(s) from 'context7':
  resolve-library-id   # 解析套件名 → Context7 庫 ID
  query-docs           # 查詢版本化文件與範例
✓ Saved 'context7' to ~/.hermes/config.yaml (2/2 tools enabled)
```
`hermes mcp list` → `context7  https://mcp.context7.com/mcp  all  ✓ enabled`

### 管理面
| 子指令 | 用途 |
|---|---|
| list / test | 列出 / 測試連線 |
| remove | 移除 |
| configure | 切換啟用的工具 |
| login / reauth | OAuth 伺服器重新認證 |
| catalog | 官方目錄（airtable, asana, atlassian, cloudflare, context7…） |
| serve | Hermes 化身 MCP server |
| install | 安裝預設 |

## H43 踩坑與最佳實踐
| 坑 | 解法 |
|---|---|
| `mcp add` 的互動確認吃不到 pipe 輸入 | 用 pty（`printf 'n\nY\n' \| script -qec …`），auth 問題按 n、enable 按 Y |
| 加入後需開新 session 才載入 | 「Start a new session to use these tools」 |
| MCP 工具注入 context（prompt-size 的 Tool schemas 41KB 的一部分） | 只啟用需要的工具（configure） |
