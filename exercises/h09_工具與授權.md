## hermes tools 三種用法
| 方式 | 指令 | 結果 |
|---|---|---|
| 互動面板 | `hermes tools`（需真實終端/pty） | ✓ 看到完整工具開關清單 |
| 子指令 | `hermes tools list / enable / disable` | 非互動管理 |
| summary | `hermes tools --summary` | 仍要求互動終端 ⚠️ |
