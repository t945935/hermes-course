# H4 實作紀錄：三種對話模式

> 完成日期：2026-09-14 ｜ 模型：upstage/solar-pro4:free（Nous Portal）

## 三種模式實測

### ① 互動模式（hermes --cli，pty 實測）
- 啟動畫面：`Welcome to Hermes Agent! Type your message or /help for commands`
- 顯示 `25 tools · 54 skills`
- 斜線指令 `/help`、`/exit` 正常運作
- ✅ 驗證成功

### ② 單行模式（hermes -z）
跑了 4 個 one-shot：
1. 自我介紹 → Solar Pro4 正常回覆
2. 檔案能力 → 說明支援的檔案類型
3. 工具呼叫 → **web 搜尋台北天氣，回傳即時中央氣象署資料（含 UV 指數）**
4. 記憶測試 → 「記住我的常用語言是 Python」

### ③ 續接模式（hermes --continue -z）
- 先建立 session → `hermes sessions list` 看到 4 筆 session（含 ID）
- `hermes --continue -z "我剛才告訴你的程式語言是什麼？"` → **正確回覆「Python」**
- ✅ 跨 session 上下文延續成功

## 學習重點驗證
| 概念 | 實測結果 |
|---|---|
| 互動模式記住對話 | ✓ 25 tools / 54 skills 環境 |
| -z 一次性 + 工具呼叫 | ✓ 真實搜尋資料 |
| session store | ✓ ID 格式 `20260914_121340_bb3fd6` |
| --continue 續接 | ✓ 記得上一 session 內容 |

## 驗收自評
✅ 能正確選用三種模式（對話/單行/續接）
✅ 知道斜線指令在互動模式內使用
✅ 明白 session 是「上下文延續」的單位

## 注意
- 互動模式需要**真實終端**（pty/tmux），不能 pipe 進 hermes
- `hermes sessions` 是子指令管理面（list/delete/export/…）
