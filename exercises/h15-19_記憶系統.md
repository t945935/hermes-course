## H19 最佳實踐（重點！）
| 原則 | 說明 |
|---|---|
| 記憶要**精簡** | config 限制：memory 2200 字元、user profile 1375 字元 |
| 存**長期穩定事實** | 偏好/環境/風格，不存一次性任務細節 |
| § 分隔條目 | 多條目按 § 分割，勿混寫一坨 |
| ⚠️ `hermes memory reset` | 會**清空所有內建記憶**（MEMORY.md+USER.md）——不要亂跑 |
| 外部 provider | 大量/多用戶記憶才需要（mem0 等），先內建就夠 |

## 成本觀察（prompt-size 前後對比）
- user profile 421 B → 497 B（寫入記憶後）
- 每次 session 啟動都會注入 → 記憶愈多，固定成本愈高
