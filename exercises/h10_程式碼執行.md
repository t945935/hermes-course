## 實驗 2：必須真實動到磁碟（防「嘴上說說」）
> 提示詞：「用 Python 寫一個檔案 /tmp/hermes_code_test.txt，內容寫 code_execution_2026，然後用 Python 讀回來把內容印出來」

### 磁碟實證（非 LLM 幻想）：
```
$ ls -la /tmp/hermes_code_test.txt
-rw-r--r-- 1 t945935 t945935 19 Sep 14 12:17 /tmp/hermes_code_test.txt
$ cat /tmp/hermes_code_test.txt
code_execution_2026
```
→ **檔案真實存在、內容正確** = 真的執行了 Python

## 重點認知
| 概念 | 說明 |
|---|---|
| execution sandbox | 在終端/容器隔離執行（config: terminal.backend local, timeout 180） |
| 限制 | code_execution timeout: 300s、max_tool_calls: 50 |
| 判斷「真執行」 | 要求寫檔/改檔/讀回，驗證磁碟副作用 |
| 免型態 | 記憶模型也能跑 code（free 模型已實證 ✅） |
