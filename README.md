## 🗺️ 這本書在教什麼

《Hermes Agent 100 小時》是一套 **4 部・18 章・100 節** 的實作型課程：

- **第 1 部（H1-10）入門・會用**：安裝、第一次對話、CLI、工具與授權
- **第 2 部（H11-43）進階・會聰明用**：Sessions、記憶、技能、Cron、訊息平台、安全、MCP
- **第 3 部（H44-87）開發・會開發**：架構深入、技能開發、外掛開發、部署、開源貢獻
- **第 4 部（H88-100）結業**：總複習測驗、期末專題（做出專案成果）
